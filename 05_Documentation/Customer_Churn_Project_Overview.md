# Customer Churn & Retention Analysis — Project Overview

## Project Objective
Analyze customer churn, identify higher-risk customer segments, understand potential retention signals, and convert findings into actionable business recommendations.

## Business Problem
The project investigates overall churn, churn by plan and contract type, churn volume, support activity, resolution time, satisfaction, and payment behavior.

## Dataset
The analytical model uses:
- Customers
- Subscriptions
- Payments
- Customer Services
- Support Tickets
- Data Dictionary

Customers, Subscriptions, and Customer Services are customer-level tables; Payments and Support Tickets contain multiple records per customer.

## Tools
Python, Excel/CSV, MySQL, Power Query, Power BI and DAX.

## End-to-End Workflow
Raw Data → Python Cleaning & Validation → Excel/CSV Preparation → MySQL & SQL Analysis → Business/Interview Queries → Power BI Modeling → DAX → Interactive Dashboards → Dashboard Validation → Business Insights → Retention Recommendations.

## Portfolio Value
This project demonstrates an end-to-end data analyst workflow covering data preparation, validation, SQL analysis, BI reporting, business interpretation and recommendations.
